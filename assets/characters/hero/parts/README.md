# Детали героя для скелета

- `front/`, `back/` — нарезка видов спереди и сзади (`sheets/hero_*_rigpose_v1.png`). Каждая деталь — PNG в полный кадр 1024×1536, поэтому собирается без смещений.
- `rig_front.json`, `rig_back.json` — суставы, порядок слоёв (снизу вверх), пивот и родитель каждой детали.
- Места, закрытые руками и ногами, на нижних слоях дорисованы, чтобы при движении не было дыр.
- `preview_front_back.png` — проверка: покой и тестовая поза для обоих видов.
- Пересобрать: `python3 tools/cut_front_back.py`, превью: `python3 tools/pose_preview.py out.png`.
- Файлы `hero_side_*.png` в этой папке — исходные детали вида сбоку от пользователя.

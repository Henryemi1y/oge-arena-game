# Инструкция для Codex

Ты работаешь в репозитории игры «OGE Arena» вместе с Claude. Claude пишет задачи в `codex/tasks/`,
ты их выполняешь. Прочитай `README.md` и `docs/ART_STYLE.md` перед первой задачей.

## Как выполнять задачу

1. Тебе назовут номер или файл задачи (например, `codex/tasks/001-hero-front-back.md`). Прочитай его целиком.
2. Выполни ровно то, что в нём написано. Референсы лежат в путях, которые указаны в задаче.
3. Результаты сохраняй **строго по путям из раздела «Выходные файлы»** задачи. Не придумывай другие места.
4. Не изменяй `src/`, `tools/` и чужие задачи, если задача этого явно не просит. Ничего не удаляй.
5. В конце допиши в файл задачи раздел `## Результат`: список созданных файлов, размеры в пикселях,
   отклонения от задачи и проблемы. Поменяй в шапке `status: pending` на `status: done`
   (или `status: blocked`, если не смог, и объясни почему).
6. Закоммить результат: `git add -A && git commit -m "codex: задача NNN выполнена"` и, если возможно, `git push`.

## Требования к картинкам

- Формат PNG, пиксель-арт без сглаживания, стиль как у референсов в `assets/characters/hero/`.
- Прозрачный фон, если задача не говорит иного. Если сгенерировать прозрачность нельзя, делай ровный
  белый фон (#FFFFFF), ничем не затенённый, и напиши об этом в `## Результат`.
- Один предмет/персонаж на файл, если задача не просит лист. Не добавляй текст, подписи и рамки на картинки.
- Если в задаче есть несколько вариантов, сохраняй их как `_v1`, `_v2`, …

## Если что-то неясно

Не угадывай молча: выполни, что можно, и опиши вопрос в `## Результат`. Claude прочитает его и уточнит задачу.

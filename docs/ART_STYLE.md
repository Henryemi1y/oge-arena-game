# Стиль

Тёмное фэнтези, пиксель-арт с мягкой шейдинговой подачей (как в референсах героя в `assets/characters/hero/`).

## Герой
- Синий капюшон и плащ, стальные наплечники и наручи с коричневыми кожаными ремнями, белые бинты на предплечьях,
  тёмные штаны, сапоги со стальными носками, кожаный пояс с пряжкой, перчатки без пальцев.
- Меч — прямой, средневековый, с крестовидной гардой.
- Все детали рисуются в профиль (вид справа), отдельно: голова/капюшон, торс, плащ, руки, ноги, меч — для скелетной анимации.

## Общие правила
- Прозрачный фон; чёткие контуры, без размытия и градиентных фонов.
- Освещение сверху-слева; палитра приглушённая, холодная.
- Одинаковый масштаб деталей одного персонажа между файлами.

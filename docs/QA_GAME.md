# Проверка игры «Арена осколков»

Прогон: `node tools/qa_game.js <папка> critic strikes soul flow` (Playwright, Chromium без GPU). Ошибок в консоли нет.

## Анимация

| Персонаж | Скольжение стопы | Нога не достаёт | Растяжение костей | Рывок сустава: шаг / бег / старт-стоп-разворот (рад/кадр²) | Руки против ног |
|---|---|---|---|---|---|
| Герой (критик из hero_run.html, без изменений) | 0 | 0 | 0 | 0,088 общий · 0,042 бег | −0,72 |
| Гуль | 0 | 0 | 0 | 0,053 / 0,045 / 0,075 | −0,99 |
| Падший рыцарь | 0 | 0 | 0 | 0,023 / 0,020 / 0,052 | −0,99 |
| Чумной доктор | 0 | 0 | 0 | 0,020 / 0,018 / 0,076 | −0,99 |
| Козлорог | 0 | 0 | 0 | 0,028 / 0,024 / 0,035 | −1,00 |
| Каменный страж | 0 | 0 | 0 | 0,018 / 0,010 / 0,022 | −1,00 |
| Каменный палач | 0 | 0 | 0 | 0,030 / 0,014 / 0,055 | −1,00 |

Порог рывка — 0,03 (как у критика героя; рывок делится на квадрат относительной скорости, как там же).
Кадр разворота спрайта (зеркало) из рывка исключён — это не движение сустава.

Что исправлено в `src/engine/walker.js` по замечаниям критика: опорная стопа держит точку в мире (раньше скользила
при разгоне и остановке); таз не поднимается выше, чем достаёт любая нога (раньше задняя нога «не доставала»
в начале переноса); руки идут против ног по положению стоп (раньше — почти в фазе); первый шаг с места начинается
задней ногой; цель высоты таза сглажена фильтром второго порядка; доля движения сглажена во времени.

## Удары боссов

Каждый удар (кулак стража, лезвие топора палача) в момент удара решается двухкостной IK в точку, где стоял герой.
Проверено 5 дистанций × 2 глубины × 3 походки (шаг, на одной ноге, сидя): страж — 70 ударов, палач — 74;
промахов 0, наибольшая ошибка 0 px. Позы, где рука не достаёт (стоящий страж до пола, палач сидя вплотную),
ИИ не выбирает: страж тогда топает (волна по полу), палач отходит.

## Форма души

Тело героя 12 с рубит босса (4 касания клинком) — HP конечностей и героя не меняются, душа остаётся вне тела.

## Полный цикл

Неверный ответ → конечность собирается (130 → 72 HP); верные — конечность остаётся разрушенной; походка босса
меняется: шаг → прыжки на одной ноге → сидя на культях; оба босса рассыпаются; сцена победы.

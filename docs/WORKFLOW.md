# Процесс Claude ⇄ Codex

```
Claude ──(пишет)──▶ codex/tasks/NNN-*.md ──(пользователь: «Codex, выполни задачу NNN»)──▶ Codex
Codex ──(кладёт файлы)──▶ assets/...  + раздел «Результат» в файле задачи ──▶ git commit/push
Claude ──(git pull)──▶ забирает результат, обрабатывает, подключает в src/
```

- Статусы задачи в шапке файла: `pending` → `done` / `blocked`.
- Список всех задач и их статусов — `codex/INDEX.md` (обновляет Claude).
- Один файл задачи = одна законченная работа с чётким списком выходных файлов.
- Claude не правит `assets/` вручную, кроме постобработки (вырезание фона, нарезка листов, ресайз),
  а исходные файлы Codex оставляет рядом с обработанными.
- Всё, что Codex не смог или сомневается, он пишет в `## Результат`; Claude читает это при следующем pull.
